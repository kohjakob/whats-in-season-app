# Raw upstream data

Vendored verbatim so derivations are reproducible offline. Do not edit files here.

| File | Source | Fetched | License |
|---|---|---|---|
| `EcoCrop_DB.csv` | https://raw.githubusercontent.com/OpenCLIM/ecocrop/main/EcoCrop_DB.csv (FAO EcoCrop, 2,568 species x 55 columns) | 2026-09-16 | FAO data CC BY 4.0 (https://data.apps.fao.org/catalog/dataset/ecocrop) |

Key EcoCrop columns: `TOPMN`/`TOPMX` optimal mean temperature (C), `TMIN`/`TMAX` absolute
temperature range, `KTMP` killing temperature early growth, `KTMPR` killing temperature at
dormancy, `ROPMN`/`ROPMX`/`RMIN`/`RMAX` annual rainfall (mm), `GMIN`/`GMAX` produce cycle length
(days), `PHOTO` photoperiod class, `CLIZ` Koppen zones, `CAT` use category, `LIFO` life form.
Tomato is filed under its old name `Lycopersicon esculentum`.
